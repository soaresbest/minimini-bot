# Desenvolvimento

- Use Node.js 24, módulos ESM e mensagens ao usuário em português.
- Trabalhe na branch `main`. Após cada alteração lógica concluída, execute as verificações pertinentes, faça commit e sincronize com `origin/main` sem force push.
- Nunca versione configurações pessoais, chaves de API, sessões Microsoft ou dependências instaladas.
- Mantenha os instaladores Windows, Linux e macOS e o README coerentes com o comportamento do programa.
- Novas ações de IA devem passar pela validação da lista permitida; nunca execute código retornado por uma LLM.
